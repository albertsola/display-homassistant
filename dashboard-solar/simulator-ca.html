Dashboard Solar — simulador de pantalla

Reprodueix el renderitzat de la pantalla rodona (dashboard_solar.h + el lambda de pantalla d'ESPHome) al navegador. Mou els controls per definir un estat de la llar; cada flux mostrat es deriva del mateix balanç que fa servir el firmware — pv + import + discharge = load + charge + export.
